## 1. Назначение решения и бизнес-ценность

«Альфа-Курс» — образовательная платформа Альфа-Банка для малого и микробизнеса, начинающих предпринимателей и соло-фаундеров.

### Главные проблемы традиционного каталога
1. **Проблема нерелевантности**: подбор только по совпадению ключевых слов советует начинающему предпринимателю сложный аудит холдинга вместо пошагового чек-листа регистрации ИП.
2. **Низкая конверсия в платные продукты**: пользователи не понимают ценности платных курсов без предварительного решения их сиюминутной «боли».
3. **Отток и проблема холодного старта**: новички пугаются сложных анкет и уходят при первом посещении.

### Как решает задачу наша система
* **Двухстадийный гибридный RecSys**: отбор кандидатов по семантике задачи с жестким фильтром несовместимости стадий + многокритериальный ранкер.
* **Сквозная воронка монетизации (Free $\to$ Paid)**: сначала даем быстрый бесплатный инструмент/шаблон (быстрый дофамин и решение сиюминутной проблемы), а логическим следующим шагом связываем его с платным углубленным курсом.
* **Объяснимость (XAI) и следующий шаг**: каждая рекомендация содержит блок *«Почему подходит именно вам»* и конкретный *«Следующий шаг»*, стимулирующий повторные визиты на платформу.
* **Автономность (Zero-Config)**: система работает полностью автономно внутри Docker без обязательных внешних API-ключей.

## 3. Запуск одной командой через Docker

Проект полностью упакован в двухэтапный Docker-образ (`Node.js 20` для сборки фронтенда + `Python 3.12-slim` для FastAPI и раздачи статики на одном порту).

```bash
docker compose up --build
```

После старта веб-интерфейс доступен по адресу:
👉 **[http://localhost:8000](http://localhost:8000)**

Healthcheck эндпоинт:
```bash
curl http://localhost:8000/health
# {"status":"ok","service":"alfa-course-recsys","version":"1.0.0"}
```

## 4. Переменные окружения и используемые порты

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `PORT` | `8000` | Порт веб-приложения и API |
| `HOST` | `0.0.0.0` | Хост биндинга сервера |
| `LOG_LEVEL` | `info` | Уровень логирования |
| `OPENAI_API_KEY` | *(пусто)* | Опциональный ключ LLM для генерации текстов объяснений |

> [!NOTE]
> Сервис **Zero-Config**: подключение `OPENAI_API_KEY` является строго добровольным. Локальный векторизатор и алгоритмический генератор объяснений работают на 100% автономно.

## 5. Структура входных данных и каталога

Файлы данных расположены в каталоге `backend/app/data/`:
* `catalog.json`: структурированный каталог из образовательных материалов Альфа-Курса с метаданными:
  * `id`, `title`, `description`
  * `format`: `checklist`, `template`, `guide`, `video_intensive`, `deep_course`
  * `price_type`: `free`, `paid` (цена в рублях)
  * `target_stages`: `idea_and_launch`, `early_stage`, `growth_and_scaling`, `crisis_and_turnaround`
  * `target_domains`: `all`, `services`, `horeca`, `ecommerce`, `retail`, `it_and_digital`
  * `prerequisites`, `next_material_ids`, `key_takeaways`
* `test_profiles.json`: 4 эталонных профиля предпринимателей для валидации.

## 6. Пошаговый сценарий проверки для жюри

Откройте в браузере **[http://localhost:8000](http://localhost:8000)**:

### Сценарий 1: Холодный старт (Новый пользователь)
1. Нажмите кнопку **«Сбросить в холодный старт»** в правом верхнем углу витрины.
2. Система мгновенно выдает сбалансированный *«Золотой стартовый набор предпринимателя»* (ошибки первого года, навигатор по налогам, чек-лист регистрации) без требования заполнять анкету.

### Сценарий 2: Новичок Анна (Кофейня / СЭС / Налоги)
1. Выберите карточку профиля **«Анна (Начинающий предприниматель)»**.
2. Обратите внимание: первыми выдаются *«Чек-лист регистрации ИП за 3 дня»* и *«Чек-лист открытия кофейни: СЭС и Роспотребнадзор»*.
3. Сложные курсы для холдингов и финдиректоров автоматически отфильтрованы.
4. В блоке каждого курса доступно понятное обоснование и кнопка следующего шага.

### Сценарий 3: Действующий микробизнес Иван (Автосервис / Кассовый разрыв)
1. Выберите карточку профиля **«Иван (Владелец микробизнеса / Автосервис)»**.
2. Система рекомендует *«Готовый шаблон управленческого учета: ДДС, ОПиУ и платежный календарь»* и практический интенсив по ликвидации кассового разрыва.

### Сценарий 4: Масштабирование Дмитрий (Селлер Wildberries)
1. Выберите карточку **«Дмитрий (Селлер на маркетплейсах)»**.
2. В топе рекомендаций: калькулятор юнит-экономики, комплект шаблонов найма сотрудников и курс масштабирования селлера до 10 млн руб. Базовая регистрация ИП не навязывается.

### Сценарий 5: Сравнение с простым бейзлайном (Вкладка «Сравнение с бейзлайном»)
1. Перейдите на вкладку **«Сравнение с бейзлайном»**.
2. Нажмите **«Пересчитать метрики»**.
3. Изучите сравнительную таблицу:
   * **Stage Match Rate**: 100% у нашей модели против 40-60% у бейзлайна.
   * **NDCG@5 Uplift**: устойчивый прирост качества ранжирования на всех профилях.
   * Блок выявленных ошибок бейзлайна наглядно подсвечивает нерелевантные рекомендации.

### Сценарий 6: Дизайн и симулятор A/B-тестирования (Вкладка «A/B эксперимент»)
1. Перейдите на вкладку **«A/B эксперимент»**.
2. Измените ползунки ежедневного трафика (DAU) и MDE.
3. Система в реальном времени пересчитывает необходимый размер выборки, статистическую мощность теста и проекционный финансовый эффект для Альфа-Банка.

## 7. Автоматизированные тесты

Запуск полного тестового пакета:
```bash
uv run pytest -v
```
Все 8 тестов проверяют:
* Загрузку каталога и наличие бесплатных/платных продуктов.
* Корректность отработки холодного старта.
* Фильтрацию нерелевантных стадий для начинающих предпринимателей.
* Подбор для стадии масштабирования.
* Математическое превосходство гибридной модели над бейзлайном по NDCG@5.
* Работоспособность всех API эндпоинтов.

## 8. Известные ограничения и перспективы развития

1. **Ограничение на приватность данных**: в репозитории не используются персональные данные клиентов Альфа-Банка; тестирование проводится на обезличенных синтетических профилях.
2. **Контент платных продуктов**: система строго соблюдает ограничение кейса 06 и не раскрывает закрытые видео/уроки, передавая только продающее саммари и ссылку на платформу.
3. **Развитие**:
   * Внедрение графовых связей (Knowledge Graph) между продуктами экосистемы Альфа-Банка (открытие расчетного счета, онлайн-бухгалтерия, факторинг).
   * Коллаборативная фильтрация на реальном логе кликов через Two-Tower нейросеть при масштабировании аудитории платформы.
